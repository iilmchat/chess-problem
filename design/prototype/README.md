# Интерактивный прототип Chess Problem

Один HTML-файл без сборки и зависимостей: четыре экрана, RU/EN, таймер,
подсказки, продолжение и результат. Нужен, чтобы проверить композицию,
иерархию и сценарии до Android-реализации.

**Открыть:** [index.html](index.html) в любом современном браузере.

```bash
# из корня репозитория
start design/prototype/index.html        # Windows
open design/prototype/index.html         # macOS
xdg-open design/prototype/index.html     # Linux
```

Для скриншотов и отладки удобнее локальный сервер:

```bash
python -m http.server 8765
# http://127.0.0.1:8765/design/prototype/index.html
```

## Что можно проверить

| Сценарий | Как воспроизвести |
| --- | --- |
| Главная | Открыть прототип; переключить RU/EN в шапке |
| Решатель | Вкладка «Задача» или карточка «Задача дня» |
| Выбор фигуры | Тап по коню f5 — подсветятся легальные поля |
| Журнал ходов | После f5 → e7 в карточке «Ходы» появятся `1. Ne7+ 1… Kh8`, счётчик `1 / 2` |
| Решение | f5 → e7, дождаться ответа Kg8–h8, затем e7 → c8 |
| Ошибка | Выбрать f5 и трижды тапнуть по неверному полю (например, d4) |
| Продолжение | После третьей ошибки — «Продолжить»: +60 с и одна попытка |
| Повторный провал | Снова исчерпать попытку — оверлей предложит «Начать заново» |
| Пауза | Тап по таймеру; «Продолжить» возвращает в игру |
| Подсказки | Вкладка «Подсказки» или кнопка «Подсказка» в решателе |
| Идея | «Открыть» в строке «Идея» — бесплатно один раз, таймер на паузе |
| Фигура | «Открыть» — списывает 1 токен и пульсирует конь |
| Ход | «Открыть» — списывает 2 токена и рисует стрелку |
| Переворот доски | Кнопка с двумя стрелками внизу решателя |
| Результат | Вкладка «Итог» или довести решение до мата |
| Провал по времени | Подождать 3:05 или уменьшить `START_TIME` в DevTools и перезагрузить |

Вкладки «Главная / Задача / Подсказки / Итог» — обвязка прототипа, а не
продуктовая навигация. В приложении нижняя навигация — «Играть / Прогресс /
Настройки», а решатель открывается поверх неё.

## Ограничения

- **Шахматная логика упрощена.** Одна захардкоженная линия: вилка конём
  `1. Ne7+ Kh8 2. Nxc8`. Нет полных правил, рокировки, превращения, взятия на
  проходе и альтернативных решений. См. [KI-013](../../docs/KNOWN_ISSUES.md).
- **Только тап-тап.** Перетаскивание фигур не реализовано (KI-012).
- **Нет сценария 0 звёзд.** «Показать решение» появится в Android-версии
  вместе с разбором (KI-011).
- **Нет сохранения.** Перезагрузка страницы сбрасывает прогресс, токены и язык.
- **Реклама и Premium — заглушки.** Кнопки показывают toast, платежей нет.
- **Результат можно открыть вручную** вкладкой «Итог» — это демо-режим.
- **Звука и тактильной отдачи нет.** Они описаны в UI/UX-спецификации.

## Структура файла

```text
index.html
├── <style>        токены, компоненты, адаптивность, анимации
├── <svg>          спрайты фигур (#p-*) и иконок (#i-*)
├── <main>         экраны: home, solver, hints sheet, result
└── <script>       i18n, состояние, таймер, ходы, подсказки, результат
```

Все цвета, радиусы и шрифты продублированы в
[../tokens.json](../tokens.json). При изменении токенов обновить оба файла и
[UI/UX-спецификацию](../../docs/design/UI_UX_SPEC.md).

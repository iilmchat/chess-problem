## 3. Подробное описание (до 4000)

> **Chess Problem — шахматные задачи для тех, кто хочет считать точнее.**
>
> 360 реальных позиций, три уровня сложности и понятный ритм: одна задача,
> задание, таймер, разбор. Без энергии, жизней и навязчивой рекламы.
>
> **Три уровня**
> — Новичок: мат в один ход, вилки, связки, превращение.
> — Профессионал: мат в два-три хода, отвлечение, промежуточный ход, эндшпиль.
> — Гроссмейстер: тихие ходы, жертвы, цугцванг, крепости, этюдные идеи.
>
> **Как это работает**
> На доске — позиция из реальной партии. Вы читаете задание, рассчитываете
> вариант и делаете ходы. Неверный ход возвращает фигуру и не отнимает доступ
> к задаче. После решения — звёзды, опыт и короткое объяснение, почему ход
> работает.
>
> **Подсказки, которые учат**
> Сначала — идея: что искать. Потом — фигура. И только потом — конкретный ход.
> Первая идея бесплатна на каждую задачу. Все 360 задач доступны без покупок.
>
> **Прогресс**
> Звёзды по задачам и главам, точность, среднее время, серия дней и задача дня.
> Всё хранится на устройстве: аккаунт не нужен.
>
> **Офлайн и языки**
> Приложение работает без интернета. Русский и английский интерфейс, задания,
> подсказки и разборы.
>
> **Доступность**
> Крупные кнопки, масштабирование текста до 200%, TalkBack, режим для
> дальтоников и отключение анимаций.
>
> Поддерживаются телефоны и планшеты на Android 8.0 и новее.
>
> Шахматные задачи основаны на открытой базе Lichess (CC0 1.0). Lichess не
> связан с приложением и не поддерживает его.

Проверить длину в консоли; не добавлять функции, которых нет в сборке.

## 6. Иконка

| Параметр | Значение |
| --- | --- |
| Файл-концепт | [`design/icon.svg`](../design/icon.svg) |
| Формат для RuStore | PNG, 512×512 px |
| Прозрачность | нет, фон заполнен |
| Размер | до 3 МБ |
| Читаемость | проверить на 48 dp и в тёмной/светлой теме |
| Права | собственная иконка; без логотипов Lichess/Chess.com |

Экспорт:

```bash
# Пример через ImageMagick (после установки)
magick -background "#08110E" design/icon.svg -resize 512x512 \
  store/assets/icon-512.png
```

Проверить, что углы не обрезаны и фон не прозрачный.

Готовый файл: [`store/assets/icon-512.png`](assets/icon-512.png) — 512×512,
без альфа-канала, 62 КБ.

## 7. Скриншоты

Минимум **3 телефона** и **3 планшета**; рекомендуем 5 телефонов.

| # | Экран | Что показать | Подпись (3–6 слов) |
| --- | --- | --- | --- |
| 1 | Главная | Задача дня, три уровня, серия | «Одна задача — каждый день» |
| 2 | Решатель | Доска, «Мат в 2», таймер, подсказки | «Думайте, а не угадывайте» |
| 3 | Подсказки | Три уровня, прозрачная экономика | «Подсказки учат думать» |
| 4 | Результат | Три звезды, разбор, XP | «Разбор после каждого решения» |
| 5 | Прогресс | Статистика по темам, серия | «Видьте свой прогресс» |

Требования:

- реальные скриншоты с устройства/эмулятора, не из HTML-прототипа;
- без чужих логотипов, лиц и водяных знаков;
- текст читается на превью;
- не показывать Premium/рекламу, которых нет в v1.0.0;
- для планшета — портретная ориентация, как в консоли.

Имена файлов:

```text
store/assets/
├── icon-512.png
├── phone-01-home.png
├── phone-02-solver.png
├── phone-03-hints.png
├── phone-04-result.png
├── phone-05-progress.png
├── tablet-01-home.png
├── tablet-02-solver.png
└── tablet-03-progress.png
```

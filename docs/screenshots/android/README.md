# Android screenshots — v0.3.0 (180 задач)

Снимки сделаны с debug/release-сборки на эмуляторе Pixel 6 (Android 16, API 36).
Основная серия — 1080×2400 px (~392 dp); отдельно проверены 360×800 и 430×932
dp через `wm size`/`wm density`. Это не финальные store-скриншоты: они
фиксируют vertical slice и используются в документации и QA.

## Что проверено на устройстве

- Холодный запуск, загрузка 180 production-задач из generated assets.
- Тап-тап по доске, легальные ходы, ответ соперника, SAN в журнале.
- Setup-ход соперника отображается как `1…`; пользовательские ходы — с `2.`.
- Решение мата в 1 и мата в 2, звёзды и XP, показ финальной доски.
- 180 задач в 3 уровнях, 6 глав × 10 задач на уровень.
- Провал после 3 ошибок, продолжение +60 с, кап звёзд, решение после продолжения.
- Подсказки: идея, фигура, ход; списание дневного баланса.
- Пауза, выход с сохранением попытки, continue-карточка на главной.
- RU/EN с перезапуском Activity, светлая/тёмная тема, сохранение настроек.
- Room-прогресс, звёзды по уровням, серия дней, экран прогресса.

## Ограничения

- Доступны 180 из 360 задач; в UI нет demo-note, но контент-фаза
  продолжается.
- Нет drag-and-drop, TalkBack-навигации по клеткам и 0-star reveal из
  прототипа; см. `docs/KNOWN_ISSUES.md`.
- Скорость холодного запуска на эмуляторе не показательна для реального
  устройства: первый запуск включал верификацию/профилирование APK.

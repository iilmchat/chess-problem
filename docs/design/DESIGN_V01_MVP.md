## 1. Концепция

**Chess Problem** — мобильный тренажёр шахматных задач. Игрок открывает
уровень, получает позицию с реального турнира или из этюда, читает задание и
решает его на доске. На всё даётся время; за решение — звёзды, опыт и короткий
разбор. Следующая задача начинается сразу.

**Обещание:** «Одна задача. Одна минута. Один точный ход».

**Жанровые ориентиры:**

- **Lichess Puzzles** — честная сложность, темы, рейтинг, отсутствие pay-to-win.
- **Chess.com Puzzles** — полировка, задача дня, понятный мобильный ритм.
- **CT-ART / Chess King** — структурированный курс и объяснения, но без
  подписочной агрессии и «энергии».

**Чем отличаемся:**

1. **Доска — главный герой.** Никаких баннеров, лент и магазинов вокруг
   решателя. Одна позиция, одно задание, один таймер.
2. **Подсказки учат, а не выдают ответ.** Три уровня: идея → фигура → ход.
   Первая идея бесплатна, потому что именно она формирует навык.
3. **Честная экономика.** Все 360 задач бесплатны. Premium продаёт удобство и
   поддержку, а не доступ к знаниям. Нет энергии, жизней и loot box.
4. **Офлайн и без аккаунта.** Прогресс лежит на устройстве; приложение не
   просит интернет, не собирает данные и не требует входа.
5. **RU|EN с первого релиза.** Не «переведём потом»: схема контента требует
   оба языка, валидатор не пропускает пустые поля.

**Почему сейчас:** RuStore активно растёт, а ниша офлайн-тренажёров без
Google-сервисов и агрессивной монетизации остаётся свободной. Шахматы — вечный
контент: задачи не устаревают, их можно пополнять паками без сервера.

## 3. Принципы дизайна

1. **Board-first.** В решателе нет ничего, что конкурирует с доской за
   внимание. Задание, таймер и действия — вокруг, но не поверх.
2. **Одно решение за раз.** Нельзя случайно сделать ход «мимо»: выбранная
   фигура, легальные поля и подтверждение очевидны.
3. **Учим, не наказываем.** Ошибка — это данные, а не повод отнять жизнь.
   После третьей ошибки игрок может разобрать решение бесплатно.
4. **Подсказка — лестница.** Сначала идея, потом фигура, потом ход. Игрок
   может остановиться на любом уровне; каждый уровень снижает максимум звёзд.
5. **Честная монетизация.** Никакой энергии, «жизней», таймеров на открытие
   задачи и рекламы, которая прерывает решение.
6. **Офлайн по умолчанию.** Приложение работает в самолёте, метро и на
   устройстве без Google-сервисов.
7. **Доступность — часть качества.** Контраст, дальтонизм, TalkBack, крупный
   текст и моторика проверяются до релиза.

## 4. Основной игровой цикл

```text
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ Выбор задачи │ ──> │ Задание +    │ ──> │ Ходы на доске│
│ (уровень/    │     │ таймер       │     │ + ответы     │
│  глава/день) │     │              │     │ соперника    │
└──────────────┘     └──────────────┘     └──────┬───────┘
                                                  │
                       ┌──────────────────────────┴──────────┐
                       ▼                                     ▼
                ┌──────────────┐                     ┌──────────────┐
                │ Решено:      │                     │ Не решено:   │
                │ звёзды, XP,  │                     │ продолжить / │
                │ разбор       │                     │ заново /     │
                └──────┬───────┘                     │ разобрать    │
                       │                             └──────┬───────┘
                       └──────────────┬─────────────────────┘
                                      ▼
                              ┌──────────────┐
                              │ Следующая    │
                              │ задача       │
                              └──────────────┘
```

**Одна сессия:** 3–5 задач подряд либо одна задача дня. После каждой задачи —
короткий результат (1–2 секунды анимации), затем сразу следующая. Никаких
принудительных возвратов на главную.

**Дневной цикл:** задача дня → серия → недельная цель. Задача дня одинакова
для всех и работает офлайн: она выбирается детерминированно по локальной дате
из встроенного пака.

### 5.4. Типы заданий

| Тип | Формулировка RU | Формулировка EN | Критерий успеха |
| --- | --- | --- | --- |
| `MATE` | «Мат в N ходов» | "Mate in N" | Последний ход пользователя — мат |
| `WIN` | «Выиграйте материал / получите преимущество» | "Win material / get an advantage" | Линия проведена до конца; цель достигнута |
| `DRAW` | «Сделайте ничью» | "Find the draw" | Линия ведёт к пату, вечному шаху или теоретической ничьей |

Внутри `WIN` могут быть подтипы: «выиграйте ферзя», «выиграйте ладью»,
«проведите пешку», «найдите лучший ход». Текст задания локализуется, а не
собирается конкатенацией.

### 5.5. Метаданные задачи

Обязательные поля (полная схема — в
[puzzle-pack.schema.json](../../content/schema/puzzle-pack.schema.json)):

| Поле | Назначение |
| --- | --- |
| `id` | Неизменяемый ID: `nov-001`, `pro-001`, `grm-001` |
| `chapter` | ID главы |
| `fen` | Позиция **до** хода-подводки |
| `setupMove` | Ход соперника, который приводит к позиции задачи (может быть `null`) |
| `solution` | UCI-ходы: пользователь, соперник, пользователь… (нечётная длина) |
| `task` | `type` + `plies` (число ходов пользователя) |
| `rating` | Рейтинг сложности (Lichess или оценка редактора) |
| `themes` | Теги тем для статистики и подсказок |
| `timeLimitSec` | Лимит времени, рассчитанный по формуле |
| `title`, `prompt` | Локализованные заголовок и задание |
| `hints[3]` | Идея, фигура, ход — RU/EN |
| `explanation` | Короткий разбор RU/EN |
| `source` | Lichess ID/URL + лицензия или `original` |

**Важно:** в базе Lichess `FEN` — позиция до хода соперника, а первый ход в
`Moves` — это подводка. Наш пайплайн применяет её и сохраняет отдельно, чтобы
приложение могло показать короткую анимацию «соперник ошибся» и начать с
позиции, где ход у игрока. Это предотвращает классическую ошибку «первый ход
пользователя уже сделан».

## 6. Сложность и время

### 6.1. Формула времени

Время зависит от рейтинга задачи и числа ходов пользователя:

```text
timeLimitSec = clamp(roundTo5(30 + 0.09 × rating + 12 × userMoves), 60, 420)
```

| Пример | Рейтинг | Ходов | Лимит |
| --- | --- | --- | --- |
| Мат в 1, новичок | 800 | 1 | 115 с |
| Вилка, профессионал | 1450 | 2 | 185 с |
| Мат в 2, гроссмейстер | 2100 | 2 | 245 с |
| Расчётный марафон | 2300 | 5 | 310 с |

Формула — стартовая гипотеза. После плейтестов допускается сдвиг коэффициентов,
но правило «чем сложнее и длиннее, тем больше времени» сохраняется.

### 6.2. Поведение таймера

- Таймер стартует после короткой анимации входа (≈1,2 с), а не в момент
  нажатия «Решить»: игрок успевает прочитать задание.
- **Пауза:** кнопка, уход в фон, открытие подсказки, показ рекламы, системный
  диалог. На паузе доска закрыта оверлеем, чтобы нельзя было «додумать» позицию.
- **Возврат:** после фона — экран «Пауза» с кнопкой «Продолжить». Таймер не
  идёт, пока игрок не подтвердит.
- **Звук:** по умолчанию тиканья нет. Опция «звук таймера» — в настройках.
- **Цвет:** последние 20% — brass, последние 10 секунд — пульсация и haptic.
- **Ноль:** доска блокируется, показывается финальный лист.

### 6.3. Зачем таймер

Таймер создаёт фокус и делает возможными звёзды, но не является единственным
способом играть. Если игрок не уложился, он может продолжить (+60 с), начать
заново или разобрать решение. Таймер не отнимает доступ к контенту.

```text
┌─────────────────────────────────────┐
│ ←   Профессионал · Глава 3    02:14 │  ← верхняя панель
│ ┌─────────────────────────────────┐ │
│ │ Ход белых · Мат в 2             │ │  ← карточка задания
│ │ Вилка · 1 480                   │ │
│ └─────────────────────────────────┘ │
│ ┌─────────────────────────────────┐ │
│ │                                 │ │
│ │           8 × 8                 │ │  ← доска
│ │          CHESSBOARD             │ │
│ │                                 │ │
│ └─────────────────────────────────┘ │
│ Осталось 2 попытки · Найдите ход    │  ← статус
│ ┌─────────────────────────────────┐ │
│ │ Ходы                      0 / 2 │ │  ← журнал ходов
│ │ Ходы появятся после первого хода│ │
│ └─────────────────────────────────┘ │
│ [💡 Подсказка 2]  [⇅ Перевернуть]  │  ← действия
└─────────────────────────────────────┘
```

### Верхняя панель

- Назад: если задача начата — подтверждение «Выйти? Прогресс сохранится».
- Уровень · глава (или «Задача дня»).
- Таймер-пилюля: `mm:ss`, кольцо прогресса, пауза по тапу.
- Меню «…»: звук, настройки, сообщить о задаче.

### Карточка задания

- Сторона хода: «Ход белых» / «Ход чёрных» с иконкой короля.
- Тип задания: «Мат в 2», «Выиграйте ферзя», «Сделайте ничью».
- Тема (до 2 чипов) и рейтинг.
- Опционально — одна строка контекста: «Соперник только что ошибся».

### Доска

- Квадратная, максимум 560 dp, центрирована; на телефоне занимает всю ширину
  минус 24 dp.
- Координаты по краям, не поверх фигур; можно выключить.
- Подсветка: последний ход, выбранная фигура, легальные поля (точки/кольца),
  шах (красное свечение короля), правильный/неправильный ход.
- Ориентация: автоматически по стороне хода; ручной переворот; настройка
  «автоповорот».
- Взаимодействие: тап-тап и drag-and-drop. Ход подтверждается отпусканием или
  вторым тапом. Нелегальные ходы не показываются.
- Превращение: диалог с Q/R/B/N, по умолчанию ферзь; подсветка выбора.
- Рокировка и взятие на проходе — стандартные жесты, без спецкнопок.

### Действия

| Действие | Поведение |
| --- | --- |
| **Подсказка** | Открывает лист подсказок; таймер на паузе |
| **Перевернуть** | Меняет ориентацию; не влияет на таймер |
| **Ещё** | Звук, настройки, «Начать заново», «Показать решение», «Сообщить» |
| **Статус** | «Осталось N попыток», «Шах!», «Не совсем», «Хорошо!» |

### Журнал ходов

- Под статусом — компактная карточка «Ходы»: SAN-пилюли сыгранных ходов и
  счётчик «ходов пользователя / всего».
- Показывает только сыгранные ходы; будущая линия не раскрывается.
- Пустое состояние: «Ходы появятся после первого хода».
- На высоких экранах журнал вместе с доской центрируется; на коротких —
  прокручивается вместе с контентом, панель действий остаётся внизу.
- Журнал помогает в задачах на 2–3 хода и в разборе, но не заменяет разбор
  линии после решения.

## 8. Ходы, ошибки и решение

### 8.1. Три попытки

- У задачи **3 попытки** на неверные ходы.
- Неверный ход: фигура возвращается на место, красная вспышка, haptic, статус
  «Не совсем. Попробуйте другой ход». Счётчик уменьшается.
- Если ход был легальным, но не входит в решение, он всё равно считается
  ошибкой. Для `MATE` любой ход, дающий мат, принимается — даже если он не
  записан в линии.
- После третьей ошибки: лист «Попытки закончились» с вариантами:
  - **Продолжить** — +60 с и 1 попытка (1 подсказка / реклама / Premium);
  - **Начать заново** — сброс позиции и таймера, звёзды максимум 1;
  - **Показать решение** — 0 звёзд, задача помечается «разобрана».

### 8.2. Правильный ход

1. Фигура анимируется на поле (180 мс).
2. Если ход не последний — соперник отвечает по сценарию (450 мс). Ответ можно
   пропустить тапом.
3. Статус «Хорошо!» и короткая вибрация.
4. Если решение завершено — через 600 мс открывается результат.

Сценарий ответов соперника фиксирован в контенте. Игрок не должен угадывать,
куда пойдёт соперник: линия проверена редактором. Если у соперника есть
несколько ответов, в контенте выбирается один, а приложение принимает только
ходы, ведущие к цели.

### 8.3. Альтернативные решения

| Тип | Правило |
| --- | --- |
| `MATE` | Принимается любой ход, который ставит мат, даже если он не в линии |
| `WIN` | Принимается только ход из проверенной линии; контент обязан не иметь очевидного альтернативного выигрыша |
| `DRAW` | Принимается ход из линии; альтернативы проверяются редактором |

Это компромисс между честностью и стоимостью движка. Мы не запускаем
шахматный движок на устройстве: он увеличит APK, батарею и сложность. Вместо
этого — строгая контентная проверка и приём альтернативных матов.

### 8.4. Разбор решения

После финала доступен «Разбор»:

- список ходов в SAN (`1. Rd1 Kc7 2. Qb7#`);
- проигрывание линии на доске (назад/вперёд);
- объяснение идеи (2–4 предложения);
- кнопка «Повторить» (без потери прогресса) и «Следующая».

Разбор бесплатен всегда. Это учебный продукт; скрывать объяснение за платной
стеной — плохая практика.

## 9. Подсказки

### 9.1. Три уровня

| Уровень | Что показывает | Стоимость | Максимум звёзд после |
| --- | --- | --- | --- |
| **1. Идея** | Текст: что искать («ищи вилку на короля и ферзя») | Бесплатно, 1 раз на задачу | 2 |
| **2. Фигура** | Подсвечивает фигуру, которой надо ходить | 1 подсказка | 1 |
| **3. Ход** | Рисует стрелку «откуда → куда» и показывает SAN | 2 подсказки | 1 |

Подсказки открываются последовательно: нельзя сразу купить «Ход», не увидев
«Идею»? **Можно.** Игрок вправе выбрать любой уровень, но цена и потеря звёзд
растут. Это уважение к разному темпу обучения.

### 9.2. Экономика

- Стартовый запас: **3 подсказки**.
- Максимум: **5**.
- Ежедневное восстановление: +1 в день, если запас ниже 3 (не «сгорает»).
- Награды: +1 за 5 решённых задач (не более +2 в день), +1 за задачу дня.
- Premium: без лимита.
- Реклама (фаза 2): +1 подсказка за rewarded-ролик, не более 3 в день.
- Если реклама не загрузилась — не отнимаем попытку и не показываем «пустую»
  кнопку: предлагаем бесплатную «Идею» или вернуться позже.

### 9.3. UX подсказок

- Лист подсказок **ставит таймер на паузу**; после закрытия — возобновляет.
- Первая «Идея» всегда бесплатна, но только один раз на задачу.
- После использования подсказки на доске появляется ненавязчивый маркер, а в
  результате — строка «Использовано подсказок: 2».
- Подсказка не должна раскрывать ответ раньше, чем игрок попробовал. «Идея»
  описывает тему, а не конкретный ход.
- Для задач `MATE` подсказка «Ход» показывает первый ход, но не всю линию.

### 9.4. Продолжение

«Продолжение» — отдельная сущность, не подсказка:

- доступно после таймаута или третьей ошибки;
- даёт +60 секунд и 1 попытку;
- один раз за задачу;
- стоит 1 подсказку, rewarded-ролик или входит в Premium;
- после продолжения максимум звёзд — 1.

## 10. Оценка, звёзды и XP

### 10.1. Звёзды

| Звёзды | Условие |
| --- | --- |
| ★★★ | Без подсказок, 0–1 ошибка, время ≤ 60% лимита |
| ★★ | Не более 1 подсказки или 2 ошибок, время ≤ 100% лимита |
| ★ | Решено после продолжения, с 2+ подсказками или после таймаута |
| ☆ | Решение показано, задача «разобрана» |

Звёзды — не валюта и не замок. Они показывают качество решения и питают
статистику.

### 10.2. XP

```text
XP = 100
   + (stars == 3 ? 50 : stars == 2 ? 25 : 0)
   + timeBonus (0…50)
   - 20 × hintsUsed
   + dailyBonus (×1.5 за задачу дня)
```

- `timeBonus = round(50 × max(0, 1 − elapsed / limit))`.
- Минимум за решённую задачу — 10 XP.
- «Разобрано» даёт 10 XP за просмотр, но не считается решённым для звёзд.
- XP не покупается и не влияет на доступ к задачам.

### 10.3. Серия

- Серия = количество дней подряд, в которые решена хотя бы одна задача.
- Одна «мягкая» заморозка в неделю: пропущенный день не обнуляет серию, но
  заморозка не даёт XP и не считается решённым днём. Это не монетизируется.
- Максимальная серия хранится отдельно.
- Часовой пояс — локальный; смена пояса не должна «ломать» день (сравнение по
  локальной дате, а не UTC).

### 10.4. Достижения

Примеры (12 на релиз):

- Первая задача.
- 10 / 50 / 100 / 360 решённых.
- 10 задач на три звезды.
- 10 задач без подсказок.
- Серия 7 дней.
- Полностью пройденный уровень.
- Все главы «Новичка» на 3 звезды.
- Задача дня 7 дней подряд.
- «Чистый мат»: 10 матов подряд без ошибок.

Достижения локальные, без сервера и без «редкости», которой можно торговать.

## 11. Прогресс и мета

### 11.1. Что видит игрок

- **Главная:** задача дня, продолжить, три уровня, краткая статистика.
- **Уровень:** 12 глав, прогресс, звёзды, рекомендуемая следующая задача.
- **Глава:** 10 задач, звёзды по каждой, лучшее время.
- **Профиль:** решено, точность, среднее время, серия, распределение по темам.
- **Настройки:** язык, тема, доска, звук, haptics, доступность, данные.

### 11.2. Прогрессия

- Все уровни и главы открыты с первого запуска.
- «Рекомендуем» — первая нерешённая задача в выбранном уровне.
- Внутри главы задачи идут по возрастанию сложности; можно решать в любом
  порядке.
- Нет «энергии», «жизней», «ключей» и таймеров на открытие.

### 11.3. Задача дня

- Выбирается детерминированно: `hash(localDate) % puzzles.size` среди задач
  среднего пула, чтобы не выдавать мат в 1 каждый день.
- Одинакова для всех пользователей версии контента.
- Офлайн; если контент обновился, задача дня может измениться только после
  обновления приложения.
- Награда: 1,5× XP и +1 подсказка (если запас < 5).

## 12. Монетизация

### 12.1. Принципы

1. **Не продаём прогресс.** Все задачи бесплатны.
2. **Не прерываем решение.** Нет интерстишлов, баннеров на доске и рекламы
   между ходами.
3. **Реклама — только rewarded и только по желанию.**
4. **Premium — это удобство и поддержка**, а не доступ к знаниям.
5. **Никаких тёмных паттернов:** фальшивых таймеров, «последнего шанса»,
   подписок, оформленных в один тап без условий.

### 12.2. Бесплатно vs Premium

| Возможность | Бесплатно | Premium |
| --- | --- | --- |
| 360 задач | Да | Да |
| Задача дня | Да | Да |
| 3 подсказки в день | Да | Без лимита |
| «Идея» 1 раз на задачу | Да | Без лимита |
| Продолжение +60 с | 1 раз за задачу за подсказку/рекламу | Без лимита |
| Реклама | Только rewarded | Нет |
| Расширенная статистика | Базовая | Полная |
| Темы доски | 2 | Все |
| Будущие паки | Да | Да |

### 12.3. Модель

**Рекомендация: lifetime-покупка, не подписка.**

- Цена-гипотеза: **349–499 ₽** (региональные цены RuStore).
- Один платёж, навсегда, включая будущие паки задач.
- Подписка имеет смысл только при регулярном сервисном контенте (новые паки
  каждый месяц, облако, турниры). Для офлайн-тренажёра с 360 задачами lifetime
  честнее и проще.
- В v1.0.0 покупок нет: сначала бесплатный запуск, отзывы и retention.

### 12.4. Реклама

Если реклама будет подключена:

- только **rewarded** (за подсказку/продолжение);
- не более 3 роликов в день;
- таймер на паузе, звук выключен;
- согласие на обработку данных и политика конфиденциальности;
- никакой персонализации для несовершеннолетних;
- при ошибке загрузки — бесплатная альтернатива, а не «попробуйте позже»;
- рекламный SDK не должен требовать Google Play Services.

Кандидаты: Yandex Mobile Ads, VK Ads (проверить совместимость с RuStore и
требования модерации). Решение — после юридического оформления.

### 12.5. Юридическое ограничение RuStore

По документации RuStore (10.2026) подписки и встроенные покупки доступны
**ИП/юрлицам**; физлицо может публиковать бесплатное приложение. Поэтому:

- **v1.0.0:** бесплатно, без рекламы, без IAP, без INTERNET.
- **v1.1.0:** после оформления ИП/юрлица — Premium и, опционально, rewarded
  реклама; обновить политику, декларацию данных и карточку.
- Если оформление затягивается, выпускаем контентные паки и улучшения
  бесплатно; это лучше, чем серая монетизация.

## 13. Локализация RU|EN

### 13.1. Принципы

- **RU — основной язык** для RuStore; EN — полноценный второй, а не машинный
  перевод.
- Язык по умолчанию — системный; если системы нет в списке — русский.
- Переключение в настройках: «Системный / Русский / English»; применяется без
  перезапуска (per-app locales).
- Все строки — в ресурсах, без конкатенации. Плюрализация — через `plurals`.
- Контент: `title`, `prompt`, `hints`, `explanation` содержат `ru` и `en`.
- SAN-нотация остаётся международной (`K Q R B N`), чтобы не путать игроков;
  названия фигур в тексте локализуются.
- Даты, числа и время — через `Locale`; таймер всегда `mm:ss`.

### 13.2. Глоссарий

| RU | EN | Примечание |
| --- | --- | --- |
| Задача | Puzzle | Не «problem» в UI |
| Решение | Solution | Линия, а не «ответ» |
| Подсказка | Hint | Три уровня |
| Идея | Idea | Первый уровень |
| Продолжение | Continue | +60 секунд |
| Разбор | Review | Проигрывание линии |
| Серия | Streak | Дни подряд |
| Глава | Chapter | 10 задач |
| Уровень | Level | Новичок/Профессионал/Гроссмейстер |
| Мат в два | Mate in two | Не «мат за 2 хода» в EN |

### 13.3. QA локализации

- Псевдолокализация (текст +30%) на этапе разработки.
- Проверка длинных строк на 360 dp и при шрифте 200%.
- Проверка RU/EN скриншотов и плюралей (1 задача, 2 задачи, 5 задач).
- Носитель языка проверяет шахматные термины и разборы.
- Store-листинг RuStore — RU; EN-листинг — после выхода на международные
  площадки.

## 14. Доступность

| Область | Требование |
| --- | --- |
| Контраст | Текст ≥ 4.5:1; крупный текст ≥ 3:1; элементы управления ≥ 3:1 |

неудобно исследовать 64 клетки.

### 15.2. Типографика

- **Montserrat** — заголовки экранов и крупные цифры (кириллица есть).
- **Manrope** — интерфейс, текст, кнопки.
- **Roboto Mono** — SAN-нотация и табличные числа.
- Шрифты — OFL/Apache 2.0, локально, с кириллицей. Никаких системных
  «шахматных» шрифтов для фигур: фигуры — векторные.

### 15.3. Доска и фигуры

- 2 темы на старте: **Sage** (по умолчанию) и **Classic**; Premium — ещё 2.
- Фигуры — собственный векторный набор: простые, контрастные, с толстым
  силуэтом; читаются на 32 dp и на 80 dp.
- Светлые фигуры — ivory с тонкой тёмной обводкой; тёмные — ink с тонким
  светлым кантом. Не полагаться на заливку.
- Координаты — Manrope 10 sp, приглушённые, внутри поля.
- Тени — мягкие, только у доски и листов; в тёмной теме — тональные поверхности.

### 15.4. Иконка

Концепт: латунный конь в кольце-циферблате на чернильно-зелёном фоне. Кольцо
отсылает к таймеру, конь — к шахматам, латунь — к награде. Файл:
[design/icon.svg](../../design/icon.svg). Для RuStore нужен растровый PNG
512×512 без прозрачности.

### 15.5. Движение

- 120 мс — микровзаимодействия (нажатие, подсветка).
- 180 мс — ход фигуры.
- 240 мс — вход экрана, появление карточки.
- 320 мс — bottom sheet.
- Easing: `cubic-bezier(0.2, 0, 0, 1)`.
- Без параллакса, частиц и «конфетти»: награда — звёзды и мягкая вспышка.

### 15.6. Звук

- Ход, взятие, шах, мат, ошибка, успех, тиканье (опция), нажатие.
- Короткие, тихие, без музыки по умолчанию. Музыка — только в меню, опция.
- Все звуки синтезируются/лицензируются; сторонние сэмплы — только с
  разрешительной лицензией.
- Haptics: лёгкий отклик на выбор, средний на ход, двойной на ошибку.

## 20. Открытые вопросы

1. **Финальное имя.** `Chess Problem` — рабочее. Проверить «Chess Problem»,
   «Шахматные задачи» и store-вариант на уникальность.
2. **Юридическое лицо.** Когда оформляем ИП/юрлицо для Premium? До v1.1.0.
3. **Реклама.** Подключать ли rewarded вообще, или оставить только Premium?
   Решение после beta и с учётом возрастного рейтинга.
4. **Цена Premium.** 349 или 499 ₽; нужен ли региональный эксперимент.
5. **Контент.** Доля Lichess vs авторских задач; нужен ли отдельный редактор.
6. **Планшет.** Ограничиться центрированной колонкой или делать
   двухпанельный layout в v0.4.0.
7. **Аналитика.** Остаться на статистике RuStore или добавить AppMetrica с
   согласием.
8. **Уведомления.** Нужны ли локальные напоминания о задаче дня; это
   `POST_NOTIFICATIONS` и дополнительная политика.
9. **iOS.** После v1.0.0 или никогда; влияет на выбор общих модулей.

## 22. Решения, которые уже приняты

- **Нет энергии и жизней.** Это тренажёр, а не free-to-play-воронка.
- **Все 360 задач бесплатны.** Premium — удобство, не контент-гейт.
- **Три уровня, 12 глав по 10 задач.** Достаточно для «100+» и структуры.
- **Три уровня подсказок.** Идея → фигура → ход.
- **Продолжение +60 секунд.** Один раз за задачу.
- **Офлайн и без аккаунта.** Локальный прогресс, без облака в v1.0.
- **RU|EN с первого релиза.** Оба языка в схеме и валидаторе.
- **Запуск без рекламы и IAP.** Монетизация — после ИП/юрлица.
- **Kotlin + Compose + chesslib.** Без игрового движка и без собственного
  шахматного ядра.

# Контент-план Chess Problem — 360 задач

**Статус:** первая редакция · **Дата:** 28.10.2026
**Связано:** [DESIGN v0.1](DESIGN_V01_MVP.md) · [CONTENT_AUTHORING](../development/CONTENT_AUTHORING.md) ·
[схема пака](../../content/schema/puzzle-pack.schema.json)

Цель — 360 задач к v1.0.0: по 120 на каждый уровень, 12 глав по 10 задач.
План описывает состав, источники, распределение, производство и приёмку.

---

## 1. Принципы контента

1. **Одна задача — одна идея.** Игрок должен понять, чему она учит.
2. **Позиция из реальной игры или корректный этюд.** Никаких «сборных» позиций
   с нелегальной расстановкой.
3. **Один первый ход** (кроме матов, где допустимы альтернативные маты).
4. **Короткая линия.** Новичок — 1–2 хода, профессионал — 2–3, гроссмейстер —
   3–6. Длинные линии только при ясной идее.
5. **Объяснение важнее ответа.** Разбор — 2–4 предложения, без пересказа
   очевидного.
6. **Оба языка.** RU и EN обязательны; машинный перевод без редактуры — нет.
7. **Никакой политики и реальных имён.** Только шахматная задача.

## 2. Распределение по уровням

| Уровень | Задач | Глав | По 10 | Рейтинг | Среднее время | Средняя длина |
| --- | --- | --- | --- | --- | --- | --- |
| Новичок | 120 | 12 | 10 | 600–1199 | 90–150 с | 1–2 хода |
| Профессионал | 120 | 12 | 10 | 1200–1799 | 150–260 с | 2–3 хода |
| Гроссмейстер | 120 | 12 | 10 | 1800–2400+ | 240–420 с | 3–6 ходов |
| **Итого** | **360** | **36** | | | | |

### Кривая сложности внутри уровня

- Глава 1 — разминка: 70% задач ниже среднего рейтинга уровня.
- Главы 2–10 — рост: +15–25 рейтинга на задачу, с «передышками».
- Глава 11 — пик: 2–3 самые сложные задачи уровня.
- Глава 12 — смешанное повторение: все темы, средний рейтинг.

Внутри главы задачи сортируются по рейтингу, но не строго: допускается
«волна» (легче → сложнее → легче), чтобы не было ощущения стены.

## 5. Схема данных

Один файл — один уровень:

```text
content/
├── schema/
│   └── puzzle-pack.schema.json
├── puzzles/
│   ├── novice.json
│   ├── professional.json
│   └── grandmaster.json
└── samples/
    ├── novice.sample.json
    ├── professional.sample.json
    └── grandmaster.sample.json
```

Пак:

```json
{
  "schemaVersion": 1,
  "contentVersion": "2026.10.1",
  "level": "NOVICE",
  "puzzles": [
    {
      "id": "nov-001",
      "chapter": "mate-in-1",
      "fen": "6k1/5ppp/8/8/8/8/5PPP/4R1K1 w - - 0 1",
      "setupMove": null,
      "solution": ["e1e8"],
      "task": { "type": "MATE", "plies": 1 },
      "rating": 800,
      "themes": ["mateIn1", "backRankMate"],
      "timeLimitSec": 115,
      "title": { "ru": "Мат в один ход", "en": "Mate in one" },
      "prompt": {
        "ru": "Ход белых. Найдите мат в один ход.",
        "en": "White to move. Find mate in one."
      },
      "hints": [
        {
          "tier": 1,
          "ru": "Посмотрите на последнюю горизонталь: у короля нет свободного поля.",
          "en": "Look at the back rank: the king has no escape squares."
        }
      ],
      "explanation": {
        "ru": "Ладья с e1 идёт на e8 и ставит мат: король заперт пешками.",
        "en": "The rook goes from e1 to e8 and mates: the king is boxed in by pawns."
      },
      "source": {
        "provider": "lichess",
        "id": "abc123",
        "url": "https://lichess.org/training/abc123",
        "license": "CC0-1.0"
      }
    }
  ]
}
```

Полная схема — [puzzle-pack.schema.json](../../content/schema/puzzle-pack.schema.json).
Валидатор — [tools/validate-content.mjs](../../tools/validate-content.mjs).

### Важные поля

- `fen` — позиция **до** `setupMove`.
- `setupMove` — ход соперника (UCI) или `null`.
- `solution` — UCI, начиная с хода пользователя; длина нечётная.
- `task.plies` — число ходов пользователя (не общее число полуходов).
- `timeLimitSec` — по формуле из DESIGN §6.1.
- `hints` — 3 уровня; `tier` 1..3; оба языка.
- `source` — `lichess` + ID/URL + CC0 или `original`.

## 6. Производство

### 6.1. Этапы

```text
Отбор → Импорт → Машинная проверка → Ручное ревью → Локализация
→ Пак → CI → Плейтест → Релиз
```

1. **Отбор.** Фильтр Lichess: рейтинг, популярность ≥ 80, попытки ≥ 1000,
   RD ≤ 100, темы, стандартные шахматы.
2. **Импорт.** Применить `setupMove`, сохранить FEN/линию, сгенерировать SAN.
3. **Машинная проверка.** Легальность, мат, длина, дубли, время, локализация.
4. **Ручное ревью.** Уникальность, альтернативы, читаемость, объяснение.
5. **Локализация.** RU/EN, глоссарий, редактура.
6. **Пак.** JSON по уровню, `contentVersion`, сортировка.
7. **CI.** Валидатор на каждый PR.
8. **Плейтест.** 5–10 игроков на уровень; время, подсказки, разбор.
9. **Релиз.** Контент-фриз, проверка на устройстве.

### 6.2. Кто делает

| Роль | Ответственность |
| --- | --- |
| Контент-редактор | Отбор, линии, объяснения, RU/EN |
| Шахматный ревьюер | Уникальность, альтернативы, корректность |
| Локализатор | EN-редактура, глоссарий |
| QA | Валидатор, устройство, таймер, звёзды |
| Разработчик | Схема, импорт, CI, отображение |

В небольшой команде роли совмещаются, но **два глаза** на задачу обязательны:
автор линии не должен быть единственным ревьюером.

### 6.3. Темп

- 60 задач за цикл v0.2.1 (≈2 недели контента).
- 120 задач за v0.3.0 (≈2–3 недели).
- 180 задач за v0.4.0 (≈3–4 недели).
- Буфер 10% на переделку.

## 7. Приёмка задачи

Задача не попадает в релиз, если:

- [ ] FEN нелегален или не соответствует стороне хода.
- [ ] `solution` содержит нелегальный ход.
- [ ] Для MATE последний ход не мат.
- [ ] `task.plies` не совпадает с числом ходов пользователя.
- [ ] Есть очевидный альтернативный выигрыш (для WIN/DRAW).
- [ ] Дублируется FEN другой задачи.
- [ ] Нет RU или EN текста.
- [ ] Подсказка раскрывает ответ на уровне «Идея».
- [ ] Объяснение короче 40 символов или пересказывает линию.
- [ ] Время вне диапазона 60–420 с или сильно отличается от формулы.
- [ ] Есть политика, реальные имена, copyrighted-аннотации.
- [ ] Задача не проверена вторым человеком.
- [ ] Валидатор падает.

## 8. Метрики контента

После beta:

| Метрика | Цель |
| --- | --- |
| Доля решённых с первой попытки (новичок) | 55–70% |
| Доля решённых с первой попытки (профессионал) | 35–50% |
| Доля решённых с первой попытки (гроссмейстер) | 15–30% |
| Среднее использование подсказок | 0.3–0.8 на задачу |
| Доля «разобрано» | < 15% |
| Жалобы на задачу | < 1% показов |

Если задача стабильно решается слишком легко или слишком сложно — она
переезжает в другой уровень или заменяется.

## 9. Версионирование

- `schemaVersion` — ломающие изменения схемы.
- `contentVersion` — дата/номер пака: `2026.10.1`.
- ID задач неизменяемы; удалённая задача не переиспользуется.
- При обновлении контента прогресс сохраняется по ID; новые задачи
  добавляются, старые не меняют ID.
- Если задача исправлена (нелегальная линия), ID сохраняется, но
  `contentVersion` растёт; прогресс по звёздам может быть сброшен для этой
  задачи.

В приложении (О приложении → Лицензии):

В `THIRD_PARTY_LICENSES.md` — ссылка на базу и лицензию. CC0 не требует
атрибуции, но мы указываем источник этически и для доверия.

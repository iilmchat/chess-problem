## 6. Публикация

1. RuStore Консоль → «Приложения» → «Загрузить версию».
2. Загрузить подписанный AAB, дождаться обработки (файлы хранятся 14 дней).
3. Заполнить «Что нового?» из [WHATS_NEW_v1.0.0.md](../../store/WHATS_NEW_v1.0.0.md).
4. Проверить карточку, скриншоты, возраст, декларацию и URL политики.
5. Сохранить черновик → «Отправить на модерацию».
6. После одобрения — публикация; staged rollout, если доступен.
7. Мониторить краши, отзывы и установки 24–72 часа.

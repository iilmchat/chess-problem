## 6. Публикация

1. RuStore Консоль → «Приложения» → выбрать приложение → «Загрузить версию».
2. Загрузить подписанный AAB, дождаться обработки (файлы хранятся 14 дней).
3. Заполнить «Что нового?» из [RUSTORE_LISTING.md](../../store/RUSTORE_LISTING.md).
4. Проверить карточку, скриншоты, возраст и декларацию данных.
5. Сохранить черновик → «Отправить на модерацию».
6. После одобрения — публикация на 10–20% аудитории, если доступен staged rollout.
7. Мониторить краши, отзывы и установки 24–72 часа.

# ADR-0005 — Офлайн-first, без аккаунта и аналитики в v1.0

- **Статус:** Accepted
- **Дата:** 28.10.2026
- **Связано:** [DESIGN §12, §17](../../design/DESIGN_V01_MVP.md) ·
  [ARCHITECTURE §6, §11](../ARCHITECTURE.md) ·
  [PRIVACY POLICY](../../legal/PRIVACY_POLICY.md)

## Контекст

Шахматный тренажёр должен работать в метро, самолёте и на устройствах без
Google Play Services. Аккаунт, облако и аналитика добавляют:

- сетевые разрешения и политику;
- серверную инфраструктуру и стоимость;
- риски утечки данных и вопросы модерации;
- задержку первого запуска.

При этом v1.0 не продаёт подписку и не нуждается в серверной синхронизации.

## Решение

v1.0 — **офлайн-first**:

- контент лежит в APK/AAB (JSON в assets);
- прогресс — Room, настройки — DataStore;
- нет `INTERNET`, аккаунта, облака, аналитики и рекламных SDK;
- `android:allowBackup="false"`;
- все экраны работают без сети;
- задача дня выбирается локально по дате.

Любое сетевое SDK, разрешение или сбор данных — только через новое ADR,
обновление политики и декларации RuStore.

## Последствия

### Положительные

- Работает везде, включая устройства без GMS.
- Нет затрат на сервер и синхронизацию.
- Минимум разрешений: проще модерация и доверие.
- Быстрый холодный старт: контент локальный.
- Приватность по умолчанию: данные не покидают устройство.

### Отрицательные / ограничения

- Прогресс не синхронизируется между устройствами; потеря устройства = потеря
  прогресса (если нет локального экспорта).
- Нельзя удалённо править контент и собирать продуктовую аналитику.
- При добавлении рекламы/покупок придётся менять политику, разрешения и
  декларацию.
- Обновление контента — только с обновлением приложения.

### Что сделать

- [ ] Проверить, что в release нет `INTERNET` и лишних разрешений.
- [ ] Настроить `allowBackup=false` и `dataExtractionRules` для API 31+.
- [ ] Добавить экран «О приложении» с версией контента и политикой.
- [ ] Проверить авиарежим в QA.
- [ ] Для будущей синхронизации — отдельное ADR и политика.

## Альтернативы

| Вариант | Почему нет |
| --- | --- |
| Аккаунт + облако с v1.0 | Сервер, приватность, модерация; не нужно для 360 задач |
| Аналитика с первого дня | Противоречит обещанию «без сбора данных»; можно позже с согласием |
| Онлайн-контент | Задержки, офлайн-провалы, стоимость CDN; контент маленький |
| Локальный экспорт прогресса | Полезно, но не в MVP; добавить в v1.2+ |

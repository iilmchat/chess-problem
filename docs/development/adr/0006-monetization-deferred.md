# ADR-0006 — Запуск без монетизации; lifetime Premium позже

- **Статус:** Accepted
- **Дата:** 28.10.2026
- **Связано:** [DESIGN §12](../../design/DESIGN_V01_MVP.md#12-монетизация) ·
  [RUSTORE §7](../RUSTORE.md#7-монетизация-и-юридическое-ограничение)

## Контекст

RuStore (по документации на 10.2026) описывает платежи, подписки и встроенные
покупки для **ИП и юрлиц**: нужны ИНН, банковские реквизиты и УКЭП. У проекта
на старте нет оформленного юридического лица.

При этом продукт должен выйти быстро, собрать отзывы и не нарушать правила
магазина. Монетизация не должна портить учебный опыт: энергия, жизни,
интерстишлы и pay-to-win противоречат концепции.

## Решение

**v1.0.0 — бесплатно, без рекламы, IAP и подписок.** Все 360 задач доступны.

После оформления ИП/юрлица — **v1.1.0**:

- **lifetime Premium** (гипотеза 349–499 ₽): без лимита подсказок,
  продолжение, расширенная статистика, темы доски, будущие паки;
- **опциональная rewarded-реклама** только за подсказку/продолжение, не более
  3 роликов в день;
- никаких баннеров, интерстишлов и рекламы между ходами;
- все задачи остаются бесплатными.

Если оформление затягивается, выпускаем контент и улучшения бесплатно. Серая
монетизация (внешние платежи в обход RuStore) запрещена.

## Последствия

### Положительные

- Нет юридического блокера для первого релиза.
- Честный запуск: игрок получает полный продукт, а не демо.
- Отзывы и retention можно собрать до включения платежей.
- Lifetime проще и честнее подписки для офлайн-тренажёра.

### Отрицательные / ограничения

- Первый релиз не приносит дохода.
- Premium и реклама потребуют обновления политики, декларации данных,
  возрастной маркировки и, возможно, SDK без GMS.
- Цена и набор выгод — гипотеза; нужен эксперимент после beta.
- Реклама может ухудшить оценку 6+ и доверие; решение принимается отдельно.

### Что сделать

- [ ] Выпустить v1.0.0 без `INTERNET`, IAP и рекламных SDK.
- [ ] Оформить ИП/юрлицо и подключить платежи RuStore до v1.1.0.
- [ ] Обновить `PRIVACY_POLICY.md`, `RUSTORE.md`, декларацию данных.
- [ ] Провести A/B цены 349/399/499 ₽ после накопления отзывов.
- [ ] Не включать Premium UI, пока покупка реально недоступна.

## Альтернативы

| Вариант | Почему нет |
| --- | --- |
| Подписка с v1.0 | Нет регулярного сервисного контента; юридический блокер; хуже восприятие |
| Реклама с v1.0 | Меняет возраст/политику, рискует модерацией и доверием; нет ИП |
| Платные паки задач | Делит аудиторию и противоречит «все 360 бесплатно» |
| Энергия/жизни | Прямо противоречит принципам продукта |
| Донаты вне RuStore | Нарушает правила магазина и рискованно |

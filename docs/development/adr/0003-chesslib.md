# ADR-0003 — chesslib 1.3.7 для шахматных правил

- **Статус:** Accepted
- **Дата:** 28.10.2026
- **Связано:** [ARCHITECTURE §4](../ARCHITECTURE.md#4-шахматное-ядро) ·
  [GETTING_STARTED §5](../GETTING_STARTED.md#5-troubleshooting)

## Контекст

Приложению нужны:

- разбор FEN;
- генерация легальных ходов, включая рокировку, взятие на проходе и
  превращение;
- определение мата, пата, ничьей;
- SAN для разбора;
- стабильность на Android 8.0+ и отсутствие нативной сборки.

Собственный генератор ходов — критический риск: ошибка в правилах ломает
доверие к тренажёру. Нужна проверенная JVM-библиотека с разрешительной
лицензией.

## Решение

Используем **chesslib 1.3.7** (Apache License 2.0) через JitPack.
`core` оборачивает её в интерфейс `ChessRules` и неизменяемый
`BoardSnapshot`; UI и `data` не работают с `chesslib.Board` напрямую.

Если JitPack недоступен или версия исчезнет, вендорим исходники Apache 2.0 в
`third_party/chesslib` и собираем локально. Это не меняет контракт
`ChessRules`.

## Последствия

### Положительные

- Проверенные правила: perft, рокировка, en passant, превращение, мат/пат.
- Чистая JVM-библиотека: тесты `core` идут без эмулятора.
- Apache 2.0 совместима с проприетарным приложением при сохранении уведомлений.
- SAN и FEN из коробки — меньше собственного кода.

### Отрицательные / ограничения

- Зависимость от JitPack и конкретной версии; нужен fallback.
- Библиотека не является шахматным движком: оценку позиции и «лучший ход» она
  не даёт. Это осознанно — контент проверяется вручную.
- Нужна обёртка, чтобы не протащить `chesslib`-типы в UI и не потерять
  иммутабельность для Compose.
- При обновлении chesslib обязательны perft-тесты и проверка краевых случаев.

### Что сделать

- [ ] Добавить зависимость в `gradle/libs.versions.toml`.
- [ ] Реализовать `ChessRules`/`ChesslibRules` и `BoardSnapshot`.
- [ ] Прогнать perft: стартовая позиция depth 1–5, Kiwipete depth 1–4,
      позиции 3–6 стандартного набора.
- [ ] Добавить тесты: рокировка, en passant, превращение, мат, пат.
- [ ] Зафиксировать fallback-план в `third_party/README.md` (если понадобится).

## Альтернативы

| Вариант | Почему нет |
| --- | --- |
| Собственный генератор ходов | Высокий риск ошибок; perft и краевые случаи дорого поддерживать |
| Stockfish/движок на устройстве | Тяжёлый APK, батарея, сложность; для проверки линии не нужен |
| chess.js в WebView/JS | Лишний рантайм, медленнее, сложнее доступность и офлайн-контроль |
| Другая JVM-библиотека | Меньше известность/поддержка; chesslib уже проверена perft-набором |
| Kotlin Multiplatform chess | Для Android-only v1.0 нет выгоды; риск незрелости |

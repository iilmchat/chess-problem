## 1. Что требует RuStore

| Параметр | Требование |
| --- | --- |
| Формат | APK **или** AAB |
| Размер | до 5 ГБ |
| Имя пакета | уникальное, не меняется между версиями |
| Подпись | обязательна; обновления — тем же сертификатом |
| `versionCode` | строго больше предыдущей версии |
| Минимальная версия | Android 8.0 (API 26) — соответствует |
| Иконка | 512×512 px, PNG/JPG, до 3 МБ, фон заполнен, без прозрачности |
| Скриншоты | не менее 3 для каждого типа устройств (телефон, планшет); до 3 МБ/5 МБ; до 2160×3840; рекомендуется 16:9 |
| Название | до 30 символов, уникальное |
| Краткое описание | до 80 символов |
| Подробное описание | до 4000 символов |
| Контакты | хотя бы один: e-mail, VK, сайт, MAX |
| Категория и возраст | обязательны; маркировки внутриигрового контента |
| Данные | декларация категорий/типов данных, чувствительности разрешений |

Роли в консоли: добавлять приложение может «Владелец компании»; загружать
версии — «Владелец», «Администратор», «Релиз-менеджер», «Разработчик».
Обработанные файлы хранятся 14 дней; если не отправить на модерацию — удаляются.

## 3. Подпись

### 3.1. Генерация ключа

```powershell
keytool -genkeypair -v `
  -keystore D:\Dev\keys\chessproblem-release.jks `
  -alias chessproblem -keyalg RSA -keysize 4096 -validity 10000
```

> Ключ — самая важная часть релиза. Сделайте резервную копию и положите в
> менеджер паролей команды. Потерянный ключ = невозможность обновить
> приложение; RuStore потребует обращения в поддержку, а версии уйдут в архив.

### 3.2. Конфигурация

`app/keystore.properties` (не коммитится):

```properties
storeFile=D:/Dev/keys/chessproblem-release.jks
storePassword=...
keyAlias=chessproblem
keyPassword=...
```

Без файла release-сборка может пройти неподписанной — для RuStore это
неприемлемо.

## 4. Сборка

```bash
./gradlew clean build
./gradlew :app:bundleRelease      # → app/build/outputs/bundle/release/app-release.aab
./gradlew :app:assembleRelease    # → app/build/outputs/apk/release/
```

- **AAB** — предпочтительно: RuStore нарежет APK под устройства. Подпись
  добавляется в консоли отдельно до загрузки.
- **APK** — проще для точечной проверки; подпись внутри.

Проверка:

```bash
$ANDROID_HOME/build-tools/36.0.0/apksigner verify --verbose --print-certs \
  app/build/outputs/apk/release/*.apk
```

## 5. Карточка приложения

### 5.1. Название

**Рабочий вариант:** `Chess Problem: шахматы` (24 символа).

Проверить уникальность в RuStore до создания ключа. Альтернативы:
«Шахматные задачи», «Chess Problem — задачи».

### 5.2. Краткое описание (до 80)

> 360 шахматных задач: три уровня, таймер, подсказки. Офлайн, RU/EN.

(70 символов)

### 5.3. Подробное описание (до 4000)

> **Chess Problem — шахматные задачи для тех, кто хочет считать точнее.**
>
> 360 реальных позиций, три уровня сложности и понятный ритм: одна задача,
> задание, таймер, разбор. Без энергии, жизней и навязчивой рекламы.
>
> **Три уровня**
> — Новичок: мат в один ход, вилки, связки, превращение.
> — Профессионал: мат в два-три хода, отвлечение, промежуточный ход, эндшпиль.
> — Гроссмейстер: тихие ходы, жертвы, цугцванг, крепости, этюдные идеи.
>
> **Как это работает**
> На доске — позиция из реальной партии. Вы читаете задание, рассчитываете
> вариант и делаете ходы. Неверный ход возвращает фигуру и не отнимает
> доступ к задаче. После решения — звёзды, опыт и короткое объяснение, почему
> ход работает.
>
> **Подсказки, которые учат**
> Сначала — идея: что искать. Потом — фигура. И только потом — конкретный ход.
> Первая идея бесплатна на каждую задачу. Все 360 задач доступны без покупок.
>
> **Прогресс**
> Звёзды по задачам и главам, точность, среднее время, серия дней и задача
> дня. Всё хранится на устройстве: аккаунт не нужен.
>
> **Офлайн и языки**
> Приложение работает без интернета. Русский и английский интерфейс, задания,
> подсказки и разборы.
>
> Поддерживаются телефоны и планшеты на Android 8.0 и новее.
>
> Шахматные задачи основаны на открытой базе Lichess (CC0 1.0). Lichess не
> связан с приложением и не поддерживает его.

## 6. Иконка и скриншоты

### 6.1. Иконка

- Концепт: [design/icon.svg](../../design/icon.svg).
- Для RuStore: PNG **512×512**, без прозрачности, фон заполнен.
- Проверить читаемость на 48 dp и в тёмной/светлой теме.
- Не использовать логотипы Lichess/Chess.com и чужие шахматные наборы.

### 6.2. Скриншоты

Минимум 3 для телефона; рекомендуем 5:

1. **Главная:** задача дня, три уровня, серия.
2. **Решатель:** доска, задание «Мат в 2», таймер, подсказки.
3. **Подсказки:** три уровня, прозрачная экономика.
4. **Результат:** три звезды, разбор, XP.
5. **Прогресс:** статистика по темам, серия.

Для планшета — 3 скриншота в альбомной/портретной ориентации (как в консоли).
Все скриншоты — с реального устройства/эмулятора, не из HTML-прототипа.
Подписи — короткие, 3–6 слов, на русском.

### 6.3. Что не делать

- Не обещать «1000 задач», если в релизе 360.
- Не писать «бесплатно» рядом с Premium, если покупка есть.
- Не использовать чужие логотипы и имена гроссмейстеров.
- Не показывать на скриншотах функции, которых нет в сборке.

## 7. Монетизация и юридическое ограничение

По документации RuStore (10.2026) подключение платежей, подписок и встроенных
покупок описано для **юрлиц и ИП**: нужны ИНН, банковские реквизиты, УКЭП.
Отдельного сценария для физлиц в разделе монетизации нет.

**План:**

| Версия | Монетизация | Условие |
| --- | --- | --- |
| v1.0.0 | Нет | Физлицо, бесплатная публикация |
| v1.1.0 | Premium lifetime + опциональная rewarded-реклама | ИП/юрлицо, политика, декларация |
| v1.2.0+ | Подписка/паки | Если есть регулярный сервисный контент |

Если монетизация задерживается — выпускаем контент бесплатно. Серая
монетизация (внешние платежи, обход RuStore) запрещена и рискованна.

### Реклама (если появится)

- Только rewarded, по желанию, не более 3/день.
- SDK без Google Play Services (Yandex Mobile Ads / VK Ads — проверить).
- Согласие, политика, декларация данных, возрастная политика.
- Никакой персонализации для несовершеннолетних.
- Не прерывать решение, не показывать баннеры на доске.

## 8. Данные и приватность

В v1.0.0:

- нет `INTERNET`, аккаунта, аналитики, рекламы, IAP;
- прогресс и настройки — только на устройстве;
- `allowBackup=false`;
- политика конфиденциальности доступна по URL (см. ниже);
- декларация RuStore: данные не собираются.

При добавлении сети/рекламы/покупок:

1. Обновить политику.
2. Обновить декларацию данных.
3. Добавить consent.
4. Проверить разрешения.
5. Обновить возрастную маркировку, если нужно.

**URL политики:** `https://iiruchating.ru/chess-problem/privacy` (план) или
GitHub Pages после публикации репозитория. До релиза — обязательно.

## 10. Чек-лист публикации

- [ ] Package и название проверены, ключ создан и сохранён.
- [ ] `versionCode` больше предыдущего.
- [ ] Release AAB/APK собран из `main`, подпись проверена `apksigner`.
- [ ] Нет `android:debuggable`, лишних разрешений, `INTERNET` в v1.0.0.
- [ ] Иконка 512×512 без прозрачности.
- [ ] ≥3 скриншота телефона + ≥3 планшета; тексты честные.
- [ ] Название ≤30, краткое ≤80, подробное ≤4000.
- [ ] Категория, возраст 6+, маркировки, контакты заполнены.
- [ ] Декларация данных: сбор отсутствует.
- [ ] Политика конфиденциальности доступна по URL.
- [ ] Лицензии Lichess/шрифтов/библиотек указаны в приложении.
- [ ] Версия отправлена на модерацию сразу после обработки файла.

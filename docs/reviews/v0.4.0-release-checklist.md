## 5. Device QA

No emulator or physical device is available in the current environment.
Everything below is still pending.

### 5.1. Drag-and-drop

- [ ] Drag a piece to a legal target: target highlight follows the finger,
  move applies, opponent replies.
- [ ] Drag to an illegal target: piece returns, mistake counter/feedback is
  correct, no crash.
- [ ] Drag back to the origin: behaves like a tap/select, does not make a move.
- [ ] Drag a pawn to the last rank: promotion chooser opens, Q/R/B/N all work.
- [ ] Drag during timer pause / disabled board does nothing.
- [ ] Drag does not conflict with vertical scrolling of the puzzle screen.
- [ ] Haptics: one short feedback on drag start only when enabled in settings.
- [ ] Drag works after board flip and with RU/EN.

### 5.2. TalkBack

- [ ] TalkBack focuses the board summary node first.
- [ ] All 64 squares are reachable; order matches the visual board and board
  flip.
- [ ] Square text includes coordinate and piece (“e4, white pawn”).
- [ ] State text includes selected / legal move / capture / check.
- [ ] Actions are “Select square …” or “Move to …”; activating a legal target
  makes the move.
- [ ] Empty squares, own pieces, opponent pieces and promotion squares are
  announced correctly.
- [ ] TalkBack does not read the canvas twice or lose focus after a move.
- [ ] RU and EN strings are complete; no missing/placeholder text.

### 5.3. Tablet and lifecycle

- [ ] 7–10" tablet: board is not tiny, layout is centered, no clipped panels.
- [ ] Font scale 200%: no clipped titles/hints/buttons.
- [ ] Light/dark theme; system bars and edge-to-edge.
- [ ] Background/return, process death, timer pause/resume.
- [ ] Airplane mode: all content and solving work.
- [ ] Cold start on a 2 GB RAM / 720p device.
